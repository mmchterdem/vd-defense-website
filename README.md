# VD DEFENSE Next.js Website

TR / EN corporate site: home, about, products, engineering, contact.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. For production: `npm run build && npm run start`.

## Before launch
- Add approved corporate email, phone, domain, and a functioning contact form endpoint.
- Verify rights to all supplied/reference images and remove third-party branding where necessary.
- Confirm claims about certifications, product ownership, specifications and protection levels before publishing.
- Confirm NATO-1/2/3 are internal model labels, not certified NATO ratings.
- Configure hosting, SSL, analytics and privacy notices as needed.
